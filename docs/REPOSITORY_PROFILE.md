## System description approval

The GitHub repository description and topics are repository-level metadata. They cannot be changed through a documentation pull request. A repository administrator can set them under **Settings → General → Repository name and description** after review. Do not present the description as a certification that deployment capital is safe. This repository contains deployable infrastructure; deployment deployment requires external audit and team-specific release approval.
