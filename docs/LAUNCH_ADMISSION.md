# Production launch admission checklist

The launch gate requires explicit positive attestation of deployment verification, chain identity, independent security-review acceptance, guardian configuration, durable state, signer configuration, and the current on-chain risk-off flag; it also rejects stale oracle, sequencer, quorum and recovery faults reported by the exchange health evaluator. This is an **operator policy library**, not an externally verified audit certificate. Supply these flags from authenticated live RPC reads, deployment manifests and reviewed audit evidence. Never claim production readiness solely because this function returns true; real network drills, key management, guardian access, liquidation flow and protocol-level independent audits remain mandatory.
