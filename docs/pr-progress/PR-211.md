## Audited implementation constraints, not acceptance waivers

The governing implementation document describes these current conservative restrictions. Verify against executable code and the acceptance criteria before treating them as suitable long-term scope:
- Standalone verifier capped at 64 claimants.
- Portfolio verifier capped at 64 raw registry entries, 256 account-market pairs and 32 markets.

- Treasury payout paths are disabled by default; maker/funding settlement may be required before payout.
- Liquidation rewards can be capped/skipped on insufficient proof or backing; preservation of legitimate earned rewards and economic liveness must still be reviewed.
